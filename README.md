This project is designed to evaluate and compare the efficiency of several sorting algorithms developed in C++. The algorithms featured are:
- Insertion Sort
- Heap Sort
- Shell Sort
- Quicksort

To get started with the project, follow these instructions:
- Clone the repository onto your computer.
- Use a C++ compiler to build the project.
- Launch the compiled program with the desired arguments.

The application includes a simple console-based interface that allows users to explore, test and benchmark each sorting method.
You can generate dataset for testing or use your own file. When using the interactive menu, you’ll be asked to provide the path to a text file containing the numbers. The required format is:
- The first line should contain a single integer indicating the total number of values.
- Each following line should contain one number per line.
